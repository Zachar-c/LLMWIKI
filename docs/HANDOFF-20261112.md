# 项目交接与功能清单

更新日期为 2026-11-12。当前工程为知识增强的智能测试用例助手，适用于本机毕业设计演示。学校正式题目和导师最终范围待作者确认。

## 快速接手

1. 阅读仓库根目录 AGENTS.md 和本文件。
2. 按 [启动指南](../验收与启动-20261112.md) 安装依赖、构建前端并使用 ChatGPT 登录 Codex。
3. 双击根目录 `start-web-chatgpt.cmd`，访问 http://127.0.0.1:8012/ 。
4. 使用 `examples/公开演示-登录测试.md` 或其他自编资料，依次验证资料、Wiki、用例生成、审查、人工确认和 CSV 导出。
5. 阅读 [验收摘要与证据](acceptance-20261112/README.md)，按相同范围开展后续修改。

## 技术结构

| 位置 | 职责 |
| --- | --- |
| frontend/src/App.vue | 资料导入、原文阅读、导航和离开保护 |
| frontend/src/WikiView.vue | Wiki 生成、编辑、来源核对和发布 |
| frontend/src/CasesView.vue | 用例生成、编辑、审查、确认和导出 |
| backend/app/main.py | 基础应用、资料接口和数据库生命周期 |
| backend/app/sources.py | 原文保存、分段、元数据和校验值 |
| backend/app/wiki.py | Wiki 草稿、引用检查、内容版本和发布 |
| backend/app/cases.py | 词项检索、用例批次、审查和 CSV |
| backend/app/chatgpt_model.py | 通过 Codex CLI 复用 ChatGPT 登录，默认 gpt-6-luna |
| backend/app/web_chatgpt.py | 当前网页服务入口，复用已有路由和前端静态资源 |
| backend/app/mcp_server.py | 本地资料列表、用例生成、用例审查工具 |
| backend/tests | 后端回归、MCP 握手和浏览器验收脚本 |

Vue 前端、FastAPI 后端、SQLite 本地存储。默认数据库路径为 `backend/data/knowledge.sqlite3`。环境与依赖版本以锁文件和启动指南为准。旧 OpenCode 与桌面桥接入口作为历史调用方式保留。

## 已实现功能

| 模块 | 能力 |
| --- | --- |
| 资料导入 | 粘贴文本、导入 UTF-8 TXT/Markdown，填写标题、来源和版本 |
| 资料保存与阅读 | 本地保存、列表、完整原文、分段查看、SHA-256 校验值 |
| Wiki 整理 | 选择资料和主题，生成草稿、编辑保存、逐段核对原文后发布 |
| 引用追溯 | 展示原文片段、来源版本和已发布 Wiki 的引用 |
| 检索增强生成 | 在所选资料中以中文词项匹配原文与已发布 Wiki，支持单字召回 |
| 用例生成 | 根据需求和证据生成标题、前置条件、步骤、预期结果及优先级 |
| AI 审查 | 提供覆盖、边界、重复和可执行性方面的建议 |
| 人工编辑确认 | 修改现有字段、核对确认并保存，查看历史批次与审查结果 |
| CSV 导出 | 导出已确认批次，包含五个用例字段、UTF-8 BOM 与公式文本保护 |
| 模型调用 | 当前网页通过已登录 Codex 调用 ChatGPT 订阅下的 GPT-6 Luna |
| MCP | 资料列表、用例生成、用例审查，后端地址可配置 |
| 编辑和审查保护 | 未保存离开提示、多标签冲突、发布版本检查、旧审查过期提示 |
| 异常反馈 | 输入校验、断网、超时、额度限制和无效模型输出提示 |

保存和 Wiki 发布可提交响应中的 `content_hash` 作为 `base_hash`，冲突返回 409。前端保留当前编辑供用户核对，旧客户端省略该字段时保留原调用方式。

## 检查与复现

在项目根目录执行后端检查，在前端目录执行构建。

```powershell
backend/.venv/Scripts/python.exe -m unittest discover -s backend/tests -v
cd frontend
npm run build
```

浏览器脚本需要可用的 Chrome 与 Playwright 模块，其第二个参数填写模块的绝对路径。

```powershell
node backend/tests/web_ui_final_e2e.cjs 'C:/实际位置/node_modules/playwright'
$env:GRAD_TEST_PROVIDER = 'chatgpt'
node backend/tests/web_ui_real_e2e.cjs 'C:/实际位置/node_modules/playwright'
```

浏览器脚本使用独立数据库和自编资料。真实脚本会消耗所选账户的模型额度，每次调用最长等待 240 秒。MCP 连接当前 8012 服务时设置 `KNOWLEDGE_API_ROOT=http://127.0.0.1:8012`。
